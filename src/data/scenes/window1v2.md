Серия 1 — «Пончик в акулу»
Дерево взаимодействий с Image Labyrinth

Основа теперь такая:

Панорама 360
→ клик по объекту
→ подэкран-крупный план
→ локальные интерактивные зоны
→ текст / выбор / мини-игра / QTE
→ предмет / флаг / заметка / очки хаоса
→ возврат на панораму
→ открытие нового объекта или перехода

Твой текущий вариант уже вводит Image Labyrinth: каждый основной экран делится на подэкраны с собственными кликабельными зонами, скрытыми предметами и мини-загадками; правильная последовательность действий открывает новые объекты или следующий экран. Второй файл усиливает это через условия condition, miniGame, unlocks, очки подготовки и очки понимания, то есть фактически переводит серию в систему JSON-узлов.

0. Формат узла взаимодействия

Каждый объект лучше хранить не как “описание”, а как узел графа.

OBJECT NODE
├─ id
├─ name
├─ hoverText
├─ clickText
├─ opensSubScene?
├─ options[]
│  ├─ label
│  ├─ reactionText
│  ├─ condition?
│  ├─ miniGame?
│  └─ effects
│     ├─ addItem
│     ├─ addNote
│     ├─ addFlag
│     ├─ unlockObject
│     ├─ unlockSubScene
│     ├─ chaosDelta
│     └─ preparationDelta
└─ repeatText
1. Глобальный граф серии
1.1 Комната стажёра
├─ зеркало → подэкран зеркала → код / хаос / записка
├─ шкаф → подэкран шкафа → униформа / тайник / ключ-карта
├─ кровать → подэкран под кроватью → карточка / имя #404
├─ будильник → подэкран будильника → код 0918
├─ тумба → подэкран замка → ключ / пропуск
└─ дверь → если есть ключ → 1.2 Отдел кадров

1.2 Отдел кадров
├─ урна → подэкран урны → заявление / имя #404
├─ кофейный автомат → подэкран автомата → имя / жетон
├─ часы → подэкран часов → скрепка-ключ / подсказка 9:18
├─ стол → подэкран заявления → вписать имя / подписать
└─ Жабс → пончик → 1.3 Главный холл

1.3 Главный холл
├─ фонтан → подэкран фонтана → баллончик тумана
├─ аквариум → подэкран аквариума → свисток охраны
├─ постер слабостей → заметки героя
├─ ЗлоСнэк → подэкран автомата → чипсы / жетон
├─ герой → QTE с подготовкой
└─ реакция героя → 1.4 Отдел Халтуры

1.4 Отдел Халтуры
├─ Гремлин → витрина гаджетов
├─ манекен → тест гаджетов
├─ генератор теней → ремонт / скидка
├─ витрина → покупка гаджета
└─ сообщение Жабса → 1.5 Лаборатория

1.5 Лаборатория
├─ химический стол → смешать аромат доступа
├─ сейф → открыть ароматом → папка МЦЕАН
├─ компьютер → пароль ЛАЕДИ → файлы роботизации
├─ прототип Жабса → диалог / сделка
└─ папка + компьютер / прототип → конец серии
